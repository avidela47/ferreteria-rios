# Ferretería Ríos

Sistema de gestión integral para una ferretería: ventas, stock, compras, fiados y reportes en un solo lugar.

> **Proyecto de uso comercial. Todos los derechos reservados.** El código se publica solo para mostrar el trabajo realizado; no está permitido copiarlo, redistribuirlo ni usarlo sin autorización (ver [LICENSE](./LICENSE)).

## Qué hace

- **Dashboard** con ventas del día y del mes, stock bajo y fiados pendientes.
- **Catálogo y stock** de productos con categorías, imágenes y bajas de stock.
- **Ventas y ventas del día**, con impresión de comprobantes.
- **Fiados** (cuentas corrientes de clientes).
- **Compras, proveedores y pedidos**.
- **Presupuestos** imprimibles.
- **Gastos e impuestos**.
- **Reportes** semanales, mensuales y análisis Pareto.
- **Roles de usuario** (administrador y vendedor) con acceso restringido por rol.

## Tecnologías

Next.js · React · TypeScript · MongoDB (Mongoose) · NextAuth · Tailwind CSS · Recharts · Zod
